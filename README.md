# Green's Portfolio

个人作品集网站，展示我的GitHub项目和技能。

GitHub仓库: [https://github.com/Genlei-Wang/green-portfolio](https://github.com/Genlei-Wang/green-portfolio)

## 技术栈

- **Next.js 16** - React框架，App Router
- **TypeScript** - 类型安全
- **Tailwind CSS** - 样式框架
- **Framer Motion** - 动画库
- **Lucide React** - 图标库

## 功能特性

- 🎨 现代化、简洁专业的设计
- 📱 完全响应式，支持移动端、平板和桌面
- 🌙 支持深色模式
- ⚡ 性能优化，使用Next.js SSR/SSG
- 🎭 流畅的动画效果
- 🔍 SEO友好

## 项目展示

网站展示了以下项目：

1. **网页笔记插件** - 快速记录网页上的想法
2. **网页背景颜色切换插件** - 一键切换暗黑模式
3. **同时问多AI插件** - 一次输入，同时向多个AI提问
4. **电脑屏幕操作自动化工具** - 录制、回放、定时运行的Windows桌面软件

## 开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 启动生产服务器
npm start
```

## 部署

项目部署在 [Vercel](https://vercel.com)，支持自动CI/CD。
